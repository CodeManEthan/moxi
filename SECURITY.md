# Security

## Reporting a vulnerability

Please report a security problem privately, not in a public issue.

1. Use GitHub's private reporting form: open
   [Report a vulnerability](https://github.com/CodeManEthan/moxi/security/advisories/new)
   on this repository's Security tab.
2. If you can't use GitHub, email codemanethan@gmail.com.

Say which package and version you ran, what you did, and what happened. A module's own
`docs/security.md`, where it has one, says what that module does and doesn't protect
against.
